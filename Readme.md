# ゲーム概要書：CatsRace（キャッツレース）

## 1. コンセプト
可愛らしい猫（Cat）を操作し、ドリフトやアイテムを駆使して最速を目指すマルチプレイヤー・レーシングゲーム。オンラインでの対戦機能に加え、リーダーボード（ランキング）やゴースト機能によるタイムアタック要素を備えている。

## 2. 基盤技術：BroccoliEngine
本作はカスタムエンジンである**BroccoliEngine**を採用している。

## 3. ゲームシステム
### 3.1 走行・ドリフトメカニクス
*   **基本移動**: 前進・後退、ステアリング操作。
*   **ドリフトシステム**:
    *   走行中に特定の入力でドリフト状態へ移行。ドリフト中はスプライトが傾き、タイヤ痕（スキッドマーク）と火花エフェクトが発生。
    *   **ドリフトゲージ**: ドリフトを継続することでゲージが蓄積され、解除時に「ドリフトブースト」が発生。
*   **FOVエフェクト**: スピードアップ時やブースト時にカメラの視野角（FOV）が変化し、スピード感を演出。

### 3.2 アイテム・ギミック
*   **保持アイテム**: マップ上のアイテム（キノコ等）を取得し、任意のタイミングでスピードブーストを使用可能。
*   **設置ギミック**: 踏むと減速する「スローフロア」などの障害物。
*   **衝突判定**: 円形・矩形・線分による衝突判定。壁への衝突時には画面揺れ（スクリーンシェイク）が発生。

### 3.3 タイムアタック・ゴースト機能
*   **ゴースト記録**: プレイヤーの走行データを記録・保存。
*   **ゴースト再生**: リーダーボード上位者の走行データを「ゴースト」としてゲーム内に登場させ、競い合うことが可能。
*   **リーダーボード**: 外部APIと通信し、マップごとのクリアタイムをランキング形式で表示。

## 4. オンライン・マルチプレイヤー
*   **ロビー機能**: ホストとしてロビーを作成、または既存のロビーを検索して参加。
*   **同期機能**: プレイヤーの位置、回転、ドリフト状態、アイテム使用状況をネットワーク経由でリアルタイム同期。
*   **レースフロー**: 全員が準備完了（Ready）になるとホストがレースを開始。全員がゴールするか制限時間が経過するとリザルト画面へ遷移。

## 5. シーン構成
1.  **LoadingScene**: EOSへのログイン、オンラインサービスの初期化。
2.  **MenuScene**: プレイヤー名設定、ロビーの作成・検索。
3.  **LobbyScene**: 参加プレイヤーの確認、準備確認、マップ選択。
4.  **GameScene (Stage1, 2...)**: レース本編。カウントダウンからゴールまで。
5.  **ClearScene**: 個人のクリアタイム、マルチプレイヤーの結果一覧、世界ランキングの表示、名前登録。

## 6. 操作方法
| 入力 | ゲームプレイ | UI操作 |
| :--- | :--- | :--- |
| **W / S / トリガー** | アクセル / ブレーキ | 上下移動 |
| **A / D / スティック** | ハンドル操作 | 左右移動 |
| **Space / ボタン1** | ドリフト | 決定 (Submit) |
| **E / ボタン3** | アイテム使用 | - |
| **F / ボタン4** | インタラクト / 再試行 | - |
| **Esc / ボタン8** | ポーズメニュー | キャンセル |
